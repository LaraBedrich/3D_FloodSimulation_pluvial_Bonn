# 3D simulation of rain-induced flooding 
# with a recurrence interval of T = 100 a in Bonn, Germany

## Project Description

The project was conducted in ArcGIS Pro. 
It included: 
- calculating watersheds of Bonn and stream upwards of Bonn,
- reclassifying landcover,
- creating a 3D local scene of Bonn,
- and simulating a 3D heavy rain event with a recurrence interval of 100 years.
  
I compared simulation results for durations of 1 hour and 12 hours.
